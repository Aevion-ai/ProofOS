## 2023-10-25 - Prevent CI Path Traversal via Untrusted Manifests
**Vulnerability:** The `.github/workflows/mirror-from-monorepo.yml` workflow parses `MIRROR_MANIFEST.md` and copies paths using `shutil.copytree` and `shutil.copy2` to a destination (`dst`) parsed directly from the manifest without validating if `dst` is safe.
**Learning:** Even internal configuration files, such as repository manifests used in CI workflows, must be treated as untrusted data sources when parsing their values for file operations. Path traversal vulnerabilities can occur if an attacker modifies the manifest file to overwrite sensitive files (e.g., `.git/config` or `.github/workflows/` files) or exfiltrate credentials.
**Prevention:** Paths parsed from these files must always be bounded and validated against intended directories to prevent arbitrary read/write CI exploits. Strip leading slashes to prevent absolute path overrides. Resolve the constructed path and validate it using `pathlib.Path.is_relative_to()` against the base directory. Explicitly reject inputs that resolve exactly to the base root, and implement denylists to protect sensitive control-plane directories (e.g., `.git`, `.jules`).
