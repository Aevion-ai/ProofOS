## 2023-10-20 - Arbitrary Path Traversal in CI Manifest Parsing
**Vulnerability:** The python script used to sync files from a monorepo parsed paths directly from `MIRROR_MANIFEST.md` via regex (`(.+?)\s*->\s*(.+?)`) and concatenated them to path objects without bounds checking. Because untrusted `.lstrip("/")` was missing and `Path.is_relative_to` validation wasn't performed, a malicious PR could provide absolute paths or `../` sequences to read/overwrite arbitrary files on the GitHub Actions runner, including secrets in `.git/config` or GitHub workflow files.
**Learning:** Even internal configuration files used in CI workflows must be treated as untrusted data sources. When defining file sync rules from text, any dynamically constructed paths must be rigorously validated to remain within expected bounds to prevent arbitrary read/write CI exploits.
**Prevention:** Always restrict paths parsed from manifests by first stripping leading slashes, resolving the paths against a definitive base directory, and explicitly verifying bounded containment using `Path.is_relative_to(base)`. Also explicitly deny paths that equate exactly to the base root to prevent self-deletion, and filter access to sensitive subdirectories like `.git` or `.jules`.
