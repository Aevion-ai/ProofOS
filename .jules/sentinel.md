## 2024-05-14 - [Path Traversal Vulnerability in CI Workflow]
**Vulnerability:** Found a critical path traversal vulnerability in `.github/workflows/mirror-from-monorepo.yml` where external/untrusted input from `MIRROR_MANIFEST.md` is directly passed to `Path()` and then used in `shutil` operations, which can be leveraged to read arbitrary files from `.monorepo` or overwrite critical files outside the intended destination (e.g., via `src: ../../../ -> target` or `target -> ../../../.git/config`).
**Learning:** Even internal configuration/manifest files should be treated as untrusted data sources when parsing their values for critical file operations.
**Prevention:** Always sanitize paths from config/manifest files using `lstrip('/')` and use `pathlib.Path.resolve().is_relative_to()` to validate that paths stay strictly within intended bounds (e.g., `.monorepo` for source, and the current working directory for destination). Additionally, blacklist sensitive destination directories like `.git` and `.jules`.
