## 2024-09-17 - Critical Path Traversal in Mirror Workflow
**Vulnerability:** The python script in `mirror-from-monorepo.yml` constructed file paths directly from the `MIRROR_MANIFEST.md` file using `Path(".monorepo") / src` and `Path(dst)` without stripping leading slashes or validating the resolved paths, allowing path traversal attacks.
**Learning:** `Path("base") / "/absolute"` resolves to `Path("/absolute")`. Thus, leading slashes can override the base path. Also, path resolution must be validated using `is_relative_to()`, and explicitly checked against exact base path matches to prevent self-deletion.
**Prevention:** Strip leading slashes (e.g., using `.lstrip('/')`) before concatenating paths. Resolve the constructed path and validate it using `pathlib.Path.is_relative_to()` against the base directory. Explicitly reject inputs that resolve exactly to the base root. Implement denylists to protect sensitive control-plane directories like `.git`, `.github`, and `.jules`.
