## 2025-02-18 - Path Traversal in CI Manifest Parsing
**Vulnerability:** The GitHub Actions workflow `mirror-from-monorepo.yml` parses `MIRROR_MANIFEST.md` to copy files from a monorepo subset. The python script extracts paths blindly without path traversal protection or ensuring they stay within expected bounds, allowing a malicious manifest change to write anywhere inside or outside the repository (including overriding `.git/config` or `.jules/sentinel.md`).
**Learning:** Even internal configuration files used in CI workflows (like a manifest) must be treated as untrusted data if they drive file operations. Parsing paths using regex without validating the resulting paths (`is_relative_to()`) can lead to arbitrary file overwrite.
**Prevention:** Always strip leading slashes (`lstrip("/")`) from parsed paths, resolve them, and validate them against the intended base directory using `pathlib.Path.is_relative_to()`. Explicitly reject operations that resolve to the root itself, and deny writes to control-plane directories like `.git` or `.jules`.
