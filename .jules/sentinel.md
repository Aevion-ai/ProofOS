## 2026-07-27 - pathlib.Path Absolute Path Traversal
**Vulnerability:** A path traversal vulnerability existed when untrusted paths (from `MIRROR_MANIFEST.md`) were concatenated to a base directory using `pathlib.Path(base) / path_string`. In Python, if `path_string` is an absolute path (e.g., `"/etc/passwd"`), `pathlib.Path` completely ignores the base directory and resolves to the absolute path itself.
**Learning:** `pathlib.Path` concatenating logic does not inherently guard against path traversal when the incoming string contains absolute paths. It acts similarly to `os.path.join`. Constructing paths safely requires stripping leading slashes and verifying the resolved path against the base directory boundaries using `.is_relative_to()`.
**Prevention:** Always strip leading slashes before joining (`untrusted_path.lstrip("/")`). Additionally, call `.resolve()` on the combined path and strictly assert that it is within the allowed bounds using `resolved_path.is_relative_to(base_dir)`.
