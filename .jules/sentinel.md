## 2026-07-11 - Critical Path Traversal Vulnerability in CI Manifests
**Vulnerability:** Found a critical path traversal vulnerability in `.github/workflows/mirror-from-monorepo.yml` where it parsed `MIRROR_MANIFEST.md` for paths to copy from an internal monorepo to the public repository. The workflow used string concatenation without proper path sanitization when evaluating `src_path = Path(".monorepo") / src` and `dst_path = Path(dst)`. A malicious pull request could update `MIRROR_MANIFEST.md` to have `src: ../../../etc/passwd` or `src: .git/config` which would be exfiltrated if a maintainer executed the sync script. Since the workflow operates with `secrets.MONOREPO_MIRROR_TOKEN`, this poses a critical credential exfiltration risk.
**Learning:** CI pipelines parsing unsanitized text (such as markdown manifests) for sensitive operations (like file manipulation and syncing between internal and public zones) introduce significant risk. Even if paths look benign, an attacker can exploit the parser to break out of intended boundaries. Standard python `pathlib.Path` concatenation does not natively prevent traversal using `..` or absolute paths.
**Prevention:** Always validate and sanitize all components of paths derived from unsanitized input files before passing them to file system operations. Specifically, verify that components do not contain `..` or `.git` and are not absolute paths `Path(src).is_absolute()`.
