## 2023-10-25 - Prevent Path Traversal in Mirror Workflow
**Vulnerability:** The `.github/workflows/mirror-from-monorepo.yml` workflow blindly parsed user-controlled file paths (`src` and `dst`) from `MIRROR_MANIFEST.md` and passed them directly to `Path()` and `shutil` operations without structural validation, which could allow path traversal or arbitrary file writes during automated syncing.
**Learning:** Even internal configuration files used by GitHub Actions workflows (like manifests) must have their payloads treated as untrusted input. Path concatenation must always be validated against directory traversal and root overrides.
**Prevention:** Always strip leading slashes from parsed paths, resolve the final combined path, and rigorously use `.is_relative_to()` to ensure the final path strictly resides within the intended base directory. Reject paths that resolve exactly to the base directory itself, and implement explicit denylists for sensitive control-plane directories (`.git`).
