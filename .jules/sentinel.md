## 2023-10-24 - [Path Traversal in Mirror Workflow]
**Vulnerability:** The mirror workflow in `.github/workflows/mirror-from-monorepo.yml` reads paths from `MIRROR_MANIFEST.md` and copies files to them using `Path(".monorepo") / src` and `Path(dst)`. However, it does not validate that `src` and `dst` do not contain path traversal characters (like `..`) or absolute paths (like `/etc/passwd`). This could allow an attacker with control over the manifest to copy arbitrary files from the runner or overwrite arbitrary files.
**Learning:** Python's `pathlib.Path` handles absolute paths in an interesting way: `Path("base") / "/absolute/path"` evaluates to `Path("/absolute/path")`. Also, `Path` operations do not resolve `..` automatically unless `.resolve()` is used. Both of these behaviors must be protected against when constructing paths from untrusted input. Path traversal checks must use `.resolve()` and verify the resulting path is within the expected base directory.
**Prevention:** Always validate constructed paths against the base directory using `path.resolve().is_relative_to(base_dir.resolve())`. Also, strip leading slashes from untrusted input before using it in `Path` division.
