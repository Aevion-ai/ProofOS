## YYYY-MM-DD - [Path Traversal in GitHub Action]
**Vulnerability:** Path traversal vulnerability in `.github/workflows/mirror-from-monorepo.yml`. The script parses paths directly from `MIRROR_MANIFEST.md` and uses them to copy files from `.monorepo` to the main repository. Without path sanitization, an attacker could supply absolute paths or paths with `../` to overwrite sensitive files (like `.git` config or `.github/workflows`) or leak files outside the intended scope.
**Learning:** Even internal or semi-trusted manifests can be manipulated. If an attacker modifies the manifest (e.g. via PR), the CI runs and performs unsafe file operations. We need to validate paths using `is_relative_to` and ensure paths are strictly bounded to the intended directories.
**Prevention:** Always strip leading slashes before path construction to prevent absolute path override, then resolve the path and validate it strictly against the base directory using `pathlib.Path.is_relative_to()`. Explicitly reject the root directory itself to prevent self-deletion, and use denylists to block sensitive control-plane directories like `.git` and `.jules` (though `.github` should be allowed here since the workflow may need to mirror CI configs).
