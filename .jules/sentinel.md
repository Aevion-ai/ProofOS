## 2024-05-18 - Prevent Path Traversal in CI Scripts
**Vulnerability:** The Python script within the GitHub Actions workflow `.github/workflows/mirror-from-monorepo.yml` was parsing source and destination file paths directly from an untrusted internal configuration file (`MIRROR_MANIFEST.md`) and using them in file operations like `shutil.copy` and `shutil.rmtree` without proper validation, leading to path traversal vulnerabilities.
**Learning:** Even internal configuration manifests must be treated as untrusted inputs when parsing them for file and directory modifications. Untrusted paths should never be directly concatenated without first stripping absolute roots, resolving the full path, and ensuring it resides strictly within intended bounds.
**Prevention:** Always sanitize parsed paths by stripping leading slashes (`.lstrip('/')`), use `.resolve()` to get the canonical path, and use `pathlib.Path.is_relative_to()` combined with boundary root equality checks (to prevent root-level tampering). Additionally, employ denylists to protect sensitive control plane directories such as `.git` and `.jules`.
