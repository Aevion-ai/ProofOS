## 2026-07-30 - Path Traversal Vulnerability in Python File Copy Automation
**Vulnerability:** A path traversal vulnerability existed in the GitHub Actions workflow (`.github/workflows/mirror-from-monorepo.yml`) responsible for mirroring files from the canonical monorepo. It concatenated user-controlled input (paths defined in `MIRROR_MANIFEST.md`) via the `/` operator (e.g. `Path(".monorepo") / src`), which bypassed the intended base directory if the input path was absolute.
**Learning:** In Python's `pathlib`, concatenating an absolute path string (like `"/etc/passwd"`) with a `Path` object using the `/` operator evaluates to the absolute path itself, ignoring the left-side base path. This allows attackers who control `MIRROR_MANIFEST.md` in the monorepo to read or write arbitrary files on the runner filesystem outside the `.monorepo` and repo root directory constraints.
**Prevention:** To prevent path traversal when constructing paths from untrusted input, always resolve the constructed path and strictly validate it using `pathlib.Path.is_relative_to()` against the allowed, absolute base directory. Never trust user input to be relative.
