## 2025-02-23 - Path Traversal via Python Path `/` Operator
**Vulnerability:** The mirror synchronization script allowed arbitrary path traversal when copying files from the source monorepo repository because it directly joined untrusted manifest paths using the `Path` `/` operator without first stripping leading slashes or validating the target.
**Learning:** Python's `pathlib.Path` `/` operator, similar to `os.path.join()`, discards the base directory and resolves to an absolute path if the appended segment begins with a slash (e.g., `Path(".monorepo") / "/etc/passwd"` results in `/etc/passwd`). This meant a malicious PR modifying `MIRROR_MANIFEST.md` could instruct the CI pipeline to overwrite or leak arbitrary CI secrets or runner files.
**Prevention:** When constructing paths from untrusted input, always strip leading slashes (e.g. `path_string.lstrip('/')`) prior to concatenation. Afterwards, resolve the path and rigorously validate it using `pathlib.Path.is_relative_to(base_dir)` to ensure the final path remains safely constrained within the intended base directory bounds.
