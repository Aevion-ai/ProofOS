## 2025-05-15 - [Path Traversal in Python with pathlib.Path]
**Vulnerability:** A path traversal vulnerability exists in the Python script embedded within `.github/workflows/mirror-from-monorepo.yml` when constructing paths for `src` and `dst` using untrusted input from `MIRROR_MANIFEST.md` via `Path(".monorepo") / src` and `Path(dst)`. Absolute path strings input to `pathlib.Path` via `/` evaluate to the absolute path itself, ignoring the intended base directory.
**Learning:** Python's `pathlib.Path` division operator (`/`) evaluates to the absolute path if the right-hand operand is an absolute path. Thus, it doesn't safely construct relative paths, enabling easy path traversal vulnerabilities when processing untrusted inputs like manifest files.
**Prevention:** To prevent path traversal vulnerabilities when constructing paths from untrusted input (e.g., manifest files), always resolve the constructed path using `.resolve()` and validate it against the allowed base directory using `pathlib.Path.is_relative_to()`. Do not rely solely on `Path(base) / input`.
