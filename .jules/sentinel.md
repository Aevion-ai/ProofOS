## 2024-10-08 - Path Traversal Vulnerability in CI Path Expansion
**Vulnerability:** In `.github/workflows/mirror-from-monorepo.yml`, `Path(".monorepo") / src` creates a catastrophic path traversal vector. Because `pathlib.Path` resolves an absolute right-hand operand by discarding the left-hand operand, if `src` in `MIRROR_MANIFEST.md` starts with a slash (e.g., `/etc/passwd`), it evaluates to `/etc/passwd` rather than a path inside `.monorepo`. An attacker modifying `MIRROR_MANIFEST.md` (e.g., via a PR) could use this to read or overwrite arbitrary system files or copy sensitive internal git directories during the mirror operation.
**Learning:** `pathlib.Path` concatenations where the right operand comes from untrusted or external configuration files (even internal manifests) are dangerous if the string isn't stripped of leading slashes or explicitly validated against the base directory using `is_relative_to`.
**Prevention:** Strip leading slashes (`.lstrip('/')`) before concatenating paths from configuration files, and enforce a strict boundary check using `pathlib.Path.is_relative_to` to ensure the final resolved path does not escape the intended root directory, explicitly rejecting the root itself to prevent catastrophic self-deletion.
