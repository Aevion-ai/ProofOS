## 2026-09-09 - Fix Path Traversal in Mirror Workflow
**Vulnerability:** The `.github/workflows/mirror-from-monorepo.yml` workflow parses paths from `MIRROR_MANIFEST.md` using `Path(".monorepo") / src` and `Path(dst)`. If an attacker modifies the manifest (or it parses untrusted input in the future), they could specify absolute paths (like `/etc/passwd`) or traversal sequences (like `../../`) to read or overwrite arbitrary files on the runner, including sensitive directories like `.git` or `.github`.
**Learning:** Python's `pathlib.Path` concatenating an absolute path (with a leading slash) simply returns the absolute path, disregarding the base. Furthermore, raw concatenation without resolving and checking bounds against a base directory allows standard path traversal.
**Prevention:** Always strip leading slashes before joining paths using `.lstrip('/')`, resolve the resulting path, and explicitly validate it using `is_relative_to()` against the intended base directory. Reject exact base directory matches and explicitly deny paths traversing sensitive locations.
