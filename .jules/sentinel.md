## 2024-05-24 - [Critical Path Traversal in Mirror Workflow]
**Vulnerability:** The Python script in `.github/workflows/mirror-from-monorepo.yml` concatenated parsed strings from `MIRROR_MANIFEST.md` directly into `Path` objects without checking if they resulted in absolute paths (which override the base path in Python's `pathlib`) or if they traversed outside the intended base directory using `..`.
**Learning:** Python's `pathlib.Path(base) / user_input` will completely discard `base` if `user_input` is an absolute path (starts with `/`). Furthermore, even if relative, it can use `..` to escape. The paths must be resolved and checked against the base using `.is_relative_to()`.
**Prevention:** Always use `.lstrip('/')` on untrusted path components before joining. After joining, always resolve the path (`.resolve()`) and verify it remains within the intended base directory using `path.is_relative_to(base_dir)`. Explicitly reject paths that resolve exactly to the base root to prevent self-deletion, and use denylists for sensitive directories like `.git` and `.github`.
