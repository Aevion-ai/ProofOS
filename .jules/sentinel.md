## 2026-09-05 - Missing Path Traversal Validations in mirror script
**Vulnerability:** The Python script embedded in `.github/workflows/mirror-from-monorepo.yml` syncs paths from MIRROR_MANIFEST.md without proper path traversal protections or directory containment validations. It directly joins strings `src_path = Path(".monorepo") / src` and `dst_path = Path(dst)` which would allow reading from (`../../etc/shadow`) or overwriting outside the repository root.
**Learning:** Hardcoded manifest configurations that control file IO are often overlooked for traditional path traversal since the input originates from a file within the repo. However, MIRROR_MANIFEST.md could be modified via PR to steal or overwrite files.
**Prevention:** Always strip leading slashes from paths (`lstrip('/')`), use `.resolve()` to normalize, and validate bounds via `.is_relative_to(base_dir)` while ensuring the result is not the base directory itself. Explicitly exclude `.git`, `.github`, and `.jules` using a denylist for extra safety against control plane overwrites.
