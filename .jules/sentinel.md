## 2025-03-09 - [Path Traversal in Mirror Workflow]
**Vulnerability:** The python script used in the `.github/workflows/mirror-from-monorepo.yml` workflow constructs file paths based on input parsed directly from the `MIRROR_MANIFEST.md` file using `Path(".monorepo") / src` and `Path(dst)`. It does not perform validation to ensure the constructed paths do not escape their expected boundary directories (e.g. via `../` or leading slashes `/`).
**Learning:** Automated workflow scripts that process seemingly trusted configuration files can introduce critical vulnerabilities like path traversal if they fail to validate constructed file paths. An attacker modifying `MIRROR_MANIFEST.md` (e.g. via a PR) could orchestrate reads of sensitive files outside `.monorepo` or overwrite critical system files by specifying an absolute path or extensive parent navigation.
**Prevention:** Always strip leading slashes from inputs used to construct paths and validate that the resolved absolute path resides strictly within the intended base directory using methods like `pathlib.Path.is_relative_to()`. Explicitly reject exact matches to the base directory and implement denylists for known sensitive directories.
