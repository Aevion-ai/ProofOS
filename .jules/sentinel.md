## 2026-09-14 - Fix Path Traversal in Mirror Workflow
**Vulnerability:** The Python script within the GitHub Actions workflow `.github/workflows/mirror-from-monorepo.yml` parsed paths from `MIRROR_MANIFEST.md` and joined them directly without validation, leading to arbitrary file reads outside the `.monorepo` directory and arbitrary file writes/overwrites anywhere on the GitHub runner.
**Learning:** Automated workflow scripts that parse configuration files (like manifests) and interact with the filesystem are highly susceptible to path traversal, especially since they run with elevated repository permissions. We must treat the contents of such files as untrusted input.
**Prevention:** Always strip leading slashes from file paths, use `.resolve()` to get absolute paths, and validate using `.is_relative_to()` against base directories. Ensure protection against reflexivity (reject exact base paths) and implement explicit denylists for sensitive control-plane directories (e.g., `.git`, `.github`, `.jules`).
