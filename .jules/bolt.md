## 2024-05-22 - Optimizing Enum Comparison in Python
**Learning:** Recreating dictionaries inside Python dunder methods (like `__ge__`) causes massive overhead (approx. 3x slower). When optimizing Python classes or Enums, avoid dynamically monkey-patching methods outside the class definition as it breaks semantics and type checking. Define the methods normally within the class, and if dictionary mapping caching is needed, reference module-level constants defined below the class instead. When doing so for Enums inheriting from `str`, use the enum instance (`self`) as the dictionary key rather than `self.value` to prevent runtime regressions.
**Action:** Extract static mapping dictionaries from frequently called methods to module-level constants to avoid recreation on each call, maintaining normal class definitions.
