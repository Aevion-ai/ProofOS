## 2024-05-15 - Enum dictionary mapping memory recreation
**Learning:** In `src/aevion_runtime/model_access_envelope.py`, the `AccessTier` enum implements comparison logic (`__ge__` and `__gt__`) by recreating a local dictionary mapping `order = {AccessTier.PUBLIC: 0, ...}` every single time the comparison operators are called. This causes unnecessary dict allocation on each comparison which can be a bottleneck during validation or when doing comparisons in hot loops.
**Action:** Lift the `order` dictionary out of the `__ge__` and `__gt__` methods to a module-level constant (or class level) to avoid dict recreation overhead. Remember that per memory instructions, when using a module-level constant for an Enum inheriting from `str`, use the enum instance (`self`) as the dictionary key rather than `self.value` to prevent runtime regressions.
