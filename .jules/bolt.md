## 2024-10-18 - Avoid Dictionary Creation in __ge__ and __gt__ Methods
**Learning:** In the `AccessTier` Enum, the `__ge__` and `__gt__` methods create a new dictionary mapping every time they are called. This causes O(1) lookups to become O(N) where N is the number of enum elements, and it has an overhead of dict creation on each comparison. Python 3.12 doesn't like combining custom types with `IntEnum` (e.g., `class MyEnum(str, IntEnum)`) due to metaclass inheritance resolution.
**Action:** When implementing ordering for Enums inherited from `str` without `IntEnum`, cache the ordering mapping as a module-level constant rather than recreating it dynamically inside the method, and ensure the module-level constant is referenced by passing the instance (`self`) as the dictionary key rather than `self.value`.
