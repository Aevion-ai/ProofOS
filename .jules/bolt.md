## 2024-05-20 - Cache Enum Ordering Dictionary
**Learning:** In Python, defining a dictionary inside an Enum's comparison dunder methods (like `__ge__`) causes the dictionary to be recreated on every comparison. When Enums are compared frequently, this creates a measurable performance bottleneck. Furthermore, dynamically mutating an Enum by trying to add an attribute to the class (e.g. `hasattr(AccessTier, "_order_dict")` and `AccessTier._order_dict = ...`) might be slow or prone to AttributeError exceptions on certain Enum metaclass implementations. A much faster, standard, and robust approach is to define a module-level dictionary mapping Enum members to integers right after the Enum definition, then using that in the comparison methods.
**Action:** Extract inline order dictionaries in Enum comparison methods to module-level dictionaries.
